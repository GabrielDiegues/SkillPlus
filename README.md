# 🚀 **SkillUpPlus 2030+**

### *Educação de Qualidade • Trabalho Decente • Crescimento Econômico*

O **SkillUpPlus 2030+** é um aplicativo mobile criado para apoiar estudantes e profissionais na **requalificação profissional**, promovendo desenvolvimento contínuo por meio de trilhas de aprendizado, autoavaliações e recomendações inteligentes baseadas em IA.

---

## 🎯 **Objetivo do Projeto**

Ajudar usuários a:

* Avaliar suas habilidades técnicas e comportamentais
* Seguir trilhas de aprendizado em áreas emergentes
* Receber recomendações personalizadas
* Acompanhar seu progresso e conquistas
* Conectar-se a oportunidades de requalificação e inclusão produtiva

---

# 📱 **Recursos do Aplicativo**

## 🔐 **Autenticação Segura**

* Login e cadastro com tratamento seguro de senha
* Autenticação via **Firebase Authentication**
* Persistência do usuário

---

## 🧭 **Principais Telas (Tab Navigation)**

### 🏠 **Home**

* Tela de boas-vindas
* Botões para:

  * **Avaliação de Habilidades**
  * **Cursos Recomendados pela IA**

---

### 🎓 **Trilhas de Aprendizagem**

* Lista de cursos disponíveis
* Busca dinâmica
* Filtro por categorias (IA, Sustentabilidade, Soft Skills, Gestão)
* Barras de progresso para cursos ativos

---

### 🤖 **Recomendações Inteligentes**

* Sugestões personalizadas geradas via **Gemini (IA)**
* Baseadas nos resultados da avaliação
* Interface simples e intuitiva

---

### 🧠 **Avaliação de Habilidades**

* Questionário com **8 perguntas**
* Mede pontos fortes e áreas de desenvolvimento
* Alimenta o sistema de recomendações inteligentes

---

## 🏆 **Recursos Extras**
* Registro completo de progresso no **Firebase Realtime Database**
* Categorias de cursos organizadas por interesse
* Recomendações adaptativas com atualização automática

---

# 🛠️ **Tecnologias Utilizadas**

| Tecnologia                         | Função                   |
| ---------------------------------- | ------------------------ |
| **React Native + Expo**            | Desenvolvimento mobile   |
| **TypeScript**                     | Segurança de tipos       |
| **Firebase Authentication**        | Login / Cadastro         |
| **Firebase Realtime Database**     | Armazenamento de dados   |
| **React Navigation (Stack + Tab)** | Fluxo de telas           |
| **Gemini AI**                      | Recomendação inteligente |

```
/src
  /screens           → Telas do app
  /components        → Componentes reutilizáveis
```

# 🌍 **Valores e Impacto**

O SkillUpPlus 2030+ foi projetado com base nos ODS da ONU:

* **ODS 4 – Educação de Qualidade**
* **ODS 8 – Trabalho Decente e Crescimento Econômico**

O objetivo é democratizar o acesso à educação e apoiar trabalhadores no desenvolvimento de competências essenciais para o futuro do trabalho.
